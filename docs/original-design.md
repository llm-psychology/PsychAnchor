# PsychAnchor
2025/8
由 PersonaGym 論文所發想

目前利用LLM分數的三大缺陷：
- 無理論錨定：缺乏心理測量學基礎，對於模型來說缺乏完整分數的資料，分不清楚感情指標的上下界
- 低復現性：相同輸入產生波動性輸出，同樣都是"60分的勇敢"，但決策每次都不一樣，倒不如直接random(0,1)
- 邏輯斷裂：各維度分數缺乏內在一致性

> 量化：「我的內向指數是 80 分。」
> 感性：「我的內向像是一場安靜的午後雷陣雨，雖然悶熱，但只有我自己懂那種節奏。」

從量化到主觀感知我們沒辦法確定給出的反應是合乎邏輯的，從主觀感知到量化我們沒辦法判定模型的給分是一致的

我該怎麼知道我對LLM說我要一個60分勇敢的感覺，他就會產生60分勇敢的回答給我
要做的事可能是讓模糊+...+模糊的東西最後加成在一起變清晰的數據，像是給定一個情況，讓那些agent去模擬回答(做MBTI問卷?)

embeddings是將文字保留上下文的語意，不知道能不能像embeddings一樣只保留文字的感情化或是用向量表達這可能是什麼人格會說出的話
這邊想做出的是去除人格互動的矛盾化，定錨在同一個基準點上避免矛盾，但有趣的是，人本來就是矛盾的，這邊目前無解
